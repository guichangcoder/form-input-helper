# 表单录入助手（多维表格边栏插件）

一个运行在飞书多维表格**侧边栏**的自定义插件，解决「批量录入」场景，包含三个模块：

1. **📝 固定值批量录入**：设定一个或多个字段为固定值（如「项目 = XX」），其余字段逐条录入，一次批量写入多条记录。
2. **🎯 记录筛选修改**：按字段条件筛选表格内已有记录（支持等于/包含/大于等于/小于等于），再批量修改/更新/清空指定字段的值。
3. **📥 Excel 批量导入**：选择本地 Excel（.xlsx / .xls / .csv）→ 配置「Excel 列 → 数据表字段」映射 → 预览校验 → 批量写入当前数据表。

## 核心特性

- **数据不出浏览器**：Excel 在本地用 SheetJS 解析，不经过任何服务器，符合飞书插件数据安全规范；写入仅通过多维表格官方 SDK 完成。
- **字段映射智能匹配**：按表头同名自动匹配，支持手动调整、跳过指定列；映射关系可「记住」，下次导入自动复用（按数据表分别记忆）。
- **单选/多选自动补选项**：Excel 或录入中出现表格里不存在的选项值时，自动创建新选项（按你的要求）。
- **类型自动转换与校验**：文本、数字（含千分位/货币符/百分号）、日期（多种格式：2024-01-01、2024/1/1、2024年1月1日、带时分秒）、复选框（是/否/1/0/true/false）、多选（逗号/分号/顿号等分隔）均自动转换；格式错误在导入前逐行提示，不会写入脏数据。
- **批量写入**：使用官方 `addRecords` 批量接口，每批 200 条，导入 5000 条以内一次完成（超过自动分批）。
- **跟随当前表**：插件打开时自动定位你正在查看的数据表；切换表时自动刷新。
- **深浅色主题自适应**：跟随多维表格浅色/深色模式。

## 环境要求

- Node.js ≥ 18（开发机已装 v22）
- 一个飞书多维表格（拥有者可自由添加自定义插件）

## 安装与启动

```bash
cd base-form-importer
npm install        # 首次安装依赖
npm run dev        # 启动开发服务器（默认 http://localhost:5173/）
```

> 构建产物命令：`npm run build`，产物输出到 `dist/`（已配置 `base:'./'` 相对路径，符合官方上架规范，后续可发布到插件中心）。

## 在多维表格中运行插件

1. 打开任意多维表格，点击右上角 **「插件」** 展开插件面板。
2. 点击 **「自定义插件」→「+ 新增插件」**。
3. 插件名称填写 `表单录入助手`，服务地址填写 `http://localhost:5173/`，点击确定。
4. 插件即出现在面板中，点击「运行」即可使用。建议在 **表格视图** 下使用（插件会操作你当前打开的数据表）。

> 本机运行模式下，`npm run dev` 需保持运行；其他协作者要使用需改为部署到公网 HTTPS 地址（本项目代码已兼容）。

## 模块一：Excel 批量导入

1. 点击「选择 Excel 文件」，选择本地 .xlsx/.xls/.csv。
2. 若文件含多个工作表，选择要导入的工作表。
3. 在「字段映射」区逐列配置：每列 Excel 表头 → 目标字段（自动按同名匹配，可手动改，可「不导入」）。
   - 灰色标签 = 该字段类型暂不支持导入（人员/附件/关联/公式等，见下表）。
   - 映射满意后可点「记住映射」，下次导入同一张表自动复用。
4. 「数据预览与校验」会显示前 20 行转换结果，并列出所有格式问题（行号 + 字段 + 原因）。
5. 确认无误后点击「导入 N 条记录」，完成后显示成功/失败明细。

## 模块二：固定值批量录入

1. 点击「+ 添加固定值字段」，选择要固定的字段（支持多个），并为每个固定字段填写固定值。
   - 例：固定「项目 = 智能工厂项目」「月份 = 2026-10」，则下面录入的每条记录都会自动带上这两列。
   - **人员字段**：点「刷新人员」后，可从本表已出现的人员列表中选择（含当前登录用户，支持多选）；目标人员不在列表时，可输入其 open_id（`ou_` 开头，逗号分隔多个）手动添加。打开插件时人员列表会自动扫描一次。
2. 在「录入记录」区填写其余字段（控件随字段类型自适应：文本/数字/日期选择器/复选框/下拉选项等），点「添加此条记录」。
3. 反复添加多条后，在「待写入记录」列表核对（可删除、清空）。
4. 点击「写入 N 条记录」，一次性批量写入；成功后可继续下一批录入。

## 模块三：记录筛选修改

1. 在「筛选条件」区点击「+ 添加筛选条件」，选择字段 → 操作符（文本：等于/包含；数字与日期：等于/大于等于/小于等于；单选/多选/人员/复选框：等于）→ 填写条件值。支持多个条件（「并且」关系）。单选字段可直接从已有选项中选择（也可输入新选项）。
2. 点击「查询匹配记录」，插件扫描当前表并列出所有命中记录（含主字段与条件字段值）。表内记录数会在下方显示。
3. 在「修改设置」区选择修改方式与字段：
   - **逐条修改**（默认）：每条命中记录独立编辑——选定要修改的字段后，每条记录下方预填当前值，逐个填写新值；留空且未勾选「清空」的字段保持原样。最多逐条编辑前 100 条，其余保持原样（可用统一修改）。
   - **统一修改**：所有命中记录统一写入相同的字段值；每个字段可填新值或勾选「清空该字段」。
4. 核对后点击「更新 N 条记录」。单选/多选出现新选项时自动创建；每批 200 条执行，完成后显示成功/失败明细（失败逐条定位）。

> 提示：筛选在本地完成，全表记录超过 10000 条时仅扫描前 10000 条（界面会提示）；如需精确处理超大数据表，建议先用视图筛选缩小范围。

## 常见问题

- **插件一直显示「正在读取数据表」**：请确认是在多维表格的插件面板中打开，且停留在表格视图；若直接浏览器访问 localhost 属正常现象（无宿主环境）。
- **提示「未能获取当前数据表」**：切换到表格视图，或刷新插件。
- **导入报「字段转换失败」**：查看失败明细中的行号与原因，多为该行某单元格格式问题；修正 Excel 后重新导入。
- **单选/多选选项没生效**：新选项在写入前自动创建，导入完成后刷新视图即可看到。
- **端口 5173 被占用**：修改 `vite.config.ts` 中 `server.port`，并在插件服务地址中填对应端口。
- **要给同事使用**：将项目部署到公网 HTTPS 地址（如 Vercel / 公司服务器），把地址填入插件即可，无需改动代码。

## 数据安全

- Excel 解析完全在浏览器本地完成，**不上传任何数据**。
- 插件仅通过飞书官方 SDK 操作当前多维表格，权限与你的登录账号一致；不向任何第三方发送数据。

## 项目结构

```
base-form-importer/
├─ index.html                # 入口页
├─ vite.config.ts            # Vite 配置（base:'./'，port 5173）
├─ src/
│  ├─ main.tsx               # 入口
│  ├─ App.tsx                # 主界面：表上下文 + 模块切换
│  ├─ theme.css              # 样式（深浅色适配）
│  ├─ constants.ts           # 字段类型支持矩阵、分隔符、批次等
│  ├─ components/
│  │  ├─ ExcelImport.tsx     # 模块一：Excel 批量导入
│  │  ├─ FixedValueInput.tsx # 模块二：固定值批量录入
│  │  ├─ RecordUpdater.tsx   # 模块三：记录筛选修改
│  │  ├─ FieldEditor.tsx     # 公共字段值编辑器（固定值/筛选/更新共用）
│  │  └─ PreviewTable.tsx    # 通用预览表格
│  └─ utils/
│     ├─ excel.ts            # SheetJS 解析（多 sheet、表头、日期）
│     ├─ convert.ts          # 值转换与校验（核心）
│     ├─ match.ts            # 记录筛选匹配（等于/包含/比较）
│     └─ sdk.ts              # SDK 封装（上下文、选项同步、批量写入）
└─ core-test.mts             # 核心逻辑回归测试（44 项断言）
```
